# Ios Capstone

## Setup
To set up the application, install the project and open it in xCode. Hit play to launch.

## Configuration
No additional configuration is needed for the app.

## Supported Versions
This application will work on iPhones and iPads on iOS version 26.5 and above.

## Credentials Procedure
Official access is granted to the app through the use of example logins through the adventurework api. Gain access to valid login information through there, then enter the username into the username field on the login screen and the password on the login screen to be able to access the app as that user.

## Architecture summary
The application uses MVVM architecture, where Models, Views, and ViewModels are all cleanly separated. Additionally, the domain layer, data layer, and UI layer are all cleanly separated from each other.

## Known limitations
The current application will not allow you to change users, add or update information in the Adventureworks API, or create actual orders.
